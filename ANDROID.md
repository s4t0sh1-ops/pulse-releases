# Pulse Android — 0.1.0 alpha 6

Устанавливай APK поверх предыдущей Pulse, не удаляя приложение. Пакет и сертификат прежние, versionCode 6. Android 8+.

## Изменения

- Вход Яндекса больше не принадлежит Activity. Ожидание переживает переход в браузер и пересоздание экрана; незавершённый вход сохраняется зашифрованно. Полученный токен сохраняется перед запросом аккаунта, чтобы временная ошибка сети не теряла уже подтверждённый вход. Есть кнопка «Я подтвердил код — проверить». Подключение показывается только после проверки аккаунта и сохранения читаемого токена.
- Обложки: обработаны пустые значения и адреса из альбома, повторная загрузка точных метаданных по ID источника, более крупные изображения SoundCloud, ограничение повторных неудачных запросов. Логотип Pulse больше не используется как обложка песни: при отсутствии картинки остаётся нейтральная музыкальная заглушка. Наличие реальной обложки определяется источником.
- Дизлайк с мягкой фиолетовой анимацией рядом с остальными кнопками. Он сохраняется локально и исключает совпадающую запись из «Для вас» и волн; ручной поиск и плейлисты доступны. Лайк и дизлайк взаимно исключаются.
- Карточка песни помещается в экран без вертикальной прокрутки. Обложка занимает оставшуюся высоту; шесть кнопок по центру, текст песни и волна всегда внизу. Есть компоновка для горизонтального экрана и увеличенного шрифта.
- Свайп мини-плеера: короткое движение содержимого и плавное появление следующей песни, без перемещения фона карточки. Отключение системных анимаций учитывается.
- Android получил отдельный подписанный канал обновлений в репозитории с запасным прежним адресом. Для старых клиентов в выпуске остаются оба манифеста; Windows продолжает получать прежнюю 0.18.

## Проверки и ограничения

48 автоматических тестов, сборка APK и инструментального APK, Lint без ошибок. Проверены шифрование и восстановление входа с имитацией сетевых ответов, сохранение/взаимное исключение лайка и дизлайка, геометрия плеера и свайпы. Подключённого физического телефона нет: настоящий вход в Яндекс, сетевое прослушивание и аппаратное отображение на Samsung/Poco не подтверждены.

Сборка из исходников: JDK 17, SDK 35. Укажи sdk.dir в local.properties и выполни gradlew.bat assembleDebug testDebugUnitTest lintDebug. Приватные ключи подписи и пользовательские сессии не распространяются. APK — тестовая альфа, подписанная прежним отладочным сертификатом. Windows EXE не менялся.
