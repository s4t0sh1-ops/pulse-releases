# Pulse Android — 0.1.0 alpha 3

Выпуск для Android 8 и новее. Установи APK поверх alpha 1 / alpha 2 без удаления приложения: идентификатор и сертификат подписи сохранены, versionCode = 3.

## Изменения alpha 3

- Telegram открывается сразу после нажатия входа; подтверждение личности остаётся в боте.
- Обязательное обучение подсвечивает настоящие кнопки поиска, любимого, плеера, волны, оформления, Яндекса, своих треков, профиля и поддержки. Назад и касание вне подсказки не пропускают шаг.
- В нижнем плеере видна обложка песни. Из профиля убраны настройка волны и экспорт диагностики. Таймер сна удалён.
- В поиске появились карточки исполнителей. На странице исполнителя — альбомы с обложками, названиями и открытием списка песен. Каталоги Яндекса и Audius загружаются постранично автоматически; SoundCloud показывает опубликованный источником список. Полнота зависит от сервиса, региона и разрешённого доступа.
- «Для вас» учитывает любимых исполнителей, жанры и историю, подбирает связанные записи и повышает приоритет новых песен знакомых исполнителей. При пустой истории используется общая подборка.
- Для импорта лайков SoundCloud достаточно имени профиля или ссылки; список /likes определяется автоматически. Частный или ограниченный сервисом список не выдаётся за полный импорт.
- Новая буква P в иконке приложения, интерфейсе, EXE и боте.
- Встроенные обязательные обновления: подписанный канал, автоматическая загрузка, проверка APK и его сертификата. После нахождения новой версии окно нельзя пропустить; можно завершить Pulse. Офлайн запуск при недоступном канале не блокируется. Android требует разрешения устанавливать обновления из Pulse и системного подтверждения установки; обойти их обычное приложение не может. Предыдущие альфы без механизма обновления нужно обновить этим APK один раз вручную.

Пройдены 28 автоматических тестов, сборка приложения и тестового APK, Android Lint без ошибок. Настоящее сетевое прослушивание, установка обновления и длительная работа на физическом Samsung/Poco пока не проверены.

## Что перенесено

- Нативный мобильный интерфейс: Manrope с весами 500/700, дымчатые панели, нижняя навигация, компактный и полноэкранный плеер, карточка волны и три последние основы волн. Долгое нажатие открывает меню песни. Имя артиста открывает каталог; нажатие песни в каталоге запускает её без автоматического открытия большого плеера.
- Поиск SoundCloud, Audius, метаданных Яндекса и файлов. Совпадения ранжируются по названию и исполнителю, с проверкой версии записи и длительности при выборе открытой копии. Оригинал не подменяется slowed/ремиксом автоматически. Наличие записи в результатах не означает разрешения на полный стрим.
- Воспроизведение, очередь, пауза, перемотка, автоматический переход, любимое, история, версии песни, настройки волны. Очередь и позиция сохраняются, после нового запуска запись восстанавливается на паузе. Уже работающий медиасервис при возвращении в приложение продолжает своё воспроизведение.
- Локальный вход/регистрация, обязательное краткое обучение, профиль с именем и био, выход и возврат по сохранённому паролю. PBKDF2-SHA256, 200 000 итераций, случайная соль; исходные пароли не сохраняются. Локальный профиль не синхронизируется с ПК. Любимое, история и оформление общие для копии на этом телефоне.
- Telegram-вход через существующий @PulseMusicHelpBot: случайный одноразовый запрос, подтверждение кода в боте, серверная проверка. Токен бота в APK отсутствует. Кнопка поддержки открывает того же бота.
- Выбор своих аудиофайлов через системный интерфейс Android с сохранением разрешения для выбранных файлов. Полного доступа ко всем файлам телефона приложение не запрашивает.
- Импорт доступной публичной страницы SoundCloud в любимое без дубликатов. Длинный список может быть неполным — об этом выводится сообщение. Постраничный импорт всей библиотеки пока не перенесён.
- Текст LRCLIB и мягкая подсветка строк при наличии настоящих таймингов. Тайминги слов не выдумываются.
- Основной Liquid Metal Vortex перенесён из шейдера Pulse. Liquid Chrome, Dark Veil, Silk и Iridescence используют те же локальные исходные компоненты, что ПК. Все параметры четырёх эффектов взяты из схем Windows; интерфейс параметров создаётся по этим схемам. Рендер ограничен до 24 кадров/с и 1× плотности, вихрь — до 320 пикселей по ширине. Анимации фона останавливаются при сворачивании.

## Музыка с выключенным экраном

Воспроизведение и очередь находятся в `PlaybackService`, отдельном от экрана приложения. Media3 `MediaSessionService` отвечает за уведомление, экран блокировки и команды гарнитуры. Audius/файлы используют ExoPlayer с аудиофокусом, реакцией на отключение наушников и сетевым режимом удержания процессора. SoundCloud использует официальный Widget API в WebView, принадлежащем сервису: экран приложения его не приостанавливает и не уничтожает. Состояние виджета передаётся в общую медиасессию; аудиофокус и ограниченное удержание процессора освобождаются на паузе, ошибке и остановке.

Полное выключение питания телефона останавливает музыку. Целевой сценарий — блокировка экрана, переход в другое приложение и закрытие окна Pulse без принудительной остановки через настройки Android.

**Физический тест с заблокированным экраном пока не выполнен.** Framework-тесты подтверждают независимость состояния SoundCloud от Activity, работу паузы, позиции, блокировки процессора и защиту от поздних событий. Они не проверяют реальный сетевой поток и ограничения прошивок Samsung/Poco. Эмулятор в этой Windows-среде завершился с ошибкой доступа к памяти; аппаратная виртуализация недоступна. Сборка остаётся альфой до проверки на телефонах.

## Устройства и размеры

Минимум Android 8 (API 26), целевая API 35. Отдельный идентификатор альфы — `fun.pulse.music.android.alpha`; будущую стабильную версию можно устанавливать отдельно. APK не содержит привязки к конкретной архитектуре процессора; используются Android и системный WebView.

Интерфейс учитывает системные панели, вырезы и клавиатуру. Проверяются ширины 320, 360, 384, 412, 480 и 600 dp, а также увеличенный текст. Основные кнопки имеют область нажатия 48 dp. Название устройства не определяет фиксированный макет. Приоритет физической проверки: Samsung S23 с One UI 8.5 пользователя, Samsung S25 и Poco друзей.

## Что ещё предстоит

- Проверка настоящего проигрывания SoundCloud/Audius и длительной фоновой работы на S23, S25 и Poco: блокировка, гарнитура, звонок, смена Wi-Fi/мобильной сети, закрытие окна и повторное открытие.
- Android-вход Google и полный постраничный импорт SoundCloud. Проверка личного Яндекс-входа и импорта на физическом телефоне.
- Смена фотографии, полноценная статистика часто слушаемого, все детали умного поиска/транслитерации ПК, продолжение бесконечной волны, расширенное управление очередью и публичные сборки APK с отдельным постоянным ключом подписи.
- Проверка WebGL на физических GPU, поворота/многооконного режима, системного увеличения масштаба и экранного диктора.

Альфа подписана стандартным отладочным Android-ключом и предназначена для локальной проверки. Для публичного выпуска нужен отдельный постоянный ключ подписи. Ни ключ, ни локальные пользовательские данные в исходный архив не включаются. Доступность треков определяется музыкальными сервисами: APK не расширяет доступ и не заменяет подписку.

## Сборка

JDK 17, Android SDK Platform 35 и Build Tools 35.0.0. В `local.properties` указывается собственный `sdk.dir`. Gradle Wrapper 8.11.1 включён; Android Gradle Plugin — 8.9.2.

```powershell
.\gradlew.bat assembleDebug testDebugUnitTest lintDebug
.\gradlew.bat assembleDebugAndroidTest
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Тестовый APK не является пользовательским приложением и отдельно не распространяется. Для подключённого тестового телефона: `gradlew.bat connectedDebugAndroidTest`.

На проверенной Windows-среде Java Unix-domain sockets приводили к сбою loopback. Для инструментов сборки использовалась локальная настройка JVM `-Djava.net.preferIPv4Stack=true -Djdk.net.unixdomain.tmpdir=C:/pulse-nonexistent-sockets`, заставляющая Java перейти на TCP loopback. Эта настройка не входит в APK и не меняет настройки телефона.

Официальные документы: [фоновое воспроизведение Media3](https://developer.android.com/media/media3/session/background-playback), [SoundCloud Widget API](https://developers.soundcloud.com/docs/api/html5-widget), [Audius](https://docs.audius.co/), [LRCLIB](https://lrclib.net/docs).
