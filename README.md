# Pulse 0.15

Windows-плеер. Готовый Pulse-0.15.exe копируется на рабочий стол. Личный профиль, пароли, токены сервисов и закрытый ключ обновлений не входят в сборку.

## Новое в 0.15

- В профиле рядом с изменением фото появилась кнопка «Выйти». Она останавливает воспроизведение, отключает личный Яндекс и возвращает обязательный экран входа / регистрации. После закрытия и повторного запуска выход сохраняется.
- Зарегистрированные на этом компьютере локальные профили можно открыть снова по почте и паролю. Хранятся только PBKDF2-хеши, а не исходные пароли. Повторная регистрация существующей почты предлагает войти.
- При входе в другой профиль не наследуются чужой пароль, имя, био или аватар. Для Google и Telegram заново требуется подтверждение у соответствующего сервиса. Локальные профили не синхронизируются с другими компьютерами.
- Музыкальная библиотека, история и настройки остаются общими для этой копии приложения на компьютере. Выход не удаляет их. Новый профиль получает обязательное обучение; для ранее обученного профиля завершение запоминается.
- Список сохранённых профилей находится в profiles.json, активный профиль — в profile.json, копии аватаров — в profile-avatars/. Эти личные файлы не входят в сборку и не должны передаваться друзьям.
- Чистая копия размещается отдельно: Pulse-Clean-0.15/Pulse.exe запускает app/Pulse.exe с независимыми данными в data/PulseMusic-0.7.1. Предыдущие папки пользователя не очищаются.
- Версия 0.15 публикуется по явной команде владельца. Следующие версии публикуются только после отдельного разрешения.

## Из 0.14

- Стартовый экран открывается во вкладке «Вход», рядом отдельная «Регистрация». Google и Telegram подтверждают вход в сервисе. Для локального профиля проверяются сохранённые почта и PBKDF2-хеш пароля; он действует на этом компьютере и не синхронизируется между устройствами.
- Форма выровнена от верхнего края, высота текста учитывает реальную ширину и шрифт. При небольшом окне прокручивается вся форма; заголовок и пояснения не сжимаются и не обрезаются.
- Профиль → «Импортировать из SoundCloud»: публичный профиль/лайки, плейлист, отдельные треки или CSV/JSON/TXT со ссылками. Добавляет метаданные в любимые Pulse без дубликатов, не скачивая аудиофайлы. Требование входа на следующей странице SoundCloud останавливает публичный импорт с явным сообщением о частичном результате. Закрытые ссылки/токены не используются. Для длинного списка подходит файл с полными ссылками; лимит 10 000 ссылок на файл и 25 МБ.
- Бот поддержки: восемь разных простых подсказок для музыки, входа, поиска, переноса, интерфейса, фонов, обновлений и других вопросов. Шаблон необязателен; вложение можно отправить до описания. Материалы поступают разработчику только после явной отправки обращения.

## Из 0.13

- Умный подбор полной записи: при недоступности источника проверяются другие совпадающие записи. Учитываются исполнитель, название, длительность и обработка; оригинал не подменяется ремиксом или slowed автоматически. В меню песни есть «Версии трека» для ручного выбора обработки.
- Очередь, выбранная песня, позиция, перемешивание и повтор сохраняются каждые пять секунд и при выходе. При следующем запуске очередь восстанавливается на паузе. Нажатие ▶ продолжает с сохранённого места. Волны SoundCloud/Audius продолжаются; устаревшая серверная сессия Яндекса не восстанавливается.
- Более точное ранжирование общего поиска: совпадение названия/исполнителя, порядок слов, транслитерация, близкие опечатки. Точная запись стоит выше популярных слабых совпадений. Ошибочная английская раскладка исправляется ограниченным дополнительным запросом. Каталог исполнителя больше не подставляется по случайному префиксу имени.
- «Настроить волну» на главной странице и в настройках: баланс/открытия/знакомые исполнители, без последних 50 прослушанных записей, исключение ремиксов/slowed/ускоренных/live/каверов. Через меню трека можно исключить исполнителя и вернуть его в настройках. Предпочтения действуют на следующие рекомендации; источники определяют ширину доступного каталога.
- Имя исполнителя в нижнем плеере и карточке песни открывает его каталог. При нескольких исполнителях появляется выбор. Для локальной песни без идентификатора открывается поиск исполнителя.
- «Обновления Pulse» в настройках: автоматическая проверка при запуске, скачивание с прогрессом и установка после нажатия «Установить и перезапустить». Профиль/библиотека/настройки сохраняются. Подписанный Ed25519 манифест и SHA-256 проверяются до установки; старые версии и сторонние адреса отклоняются. Источник: https://github.com/s4t0sh1-ops/pulse-releases/releases. Установка заменяет текущий EXE и оставляет рядом .previous.exe для возврата.

## Сохранённые возможности

- Убрана отдельная белая полоса SoundCloud над нижней панелью. Фоновый компонент не занимает места в интерфейсе. Проверены реальное воспроизведение, пауза, перемотка, продолжение и конец записи при скрытом компоненте.

- Переработана общая интеграция SoundCloud: поиск, страницы исполнителей и рекомендации читаются из публичного мобильного каталога; основной сайт и извлечение web client_id больше не являются обязательными.
- Полная открытая запись SoundCloud играет через официальный SoundCloud Widget API внутри Pulse. Управление связано с нижним плеером: пауза, перемотка, громкость, окончание и очередь. Технический виджет работает в фоне; в интерфейсе остаётся единая панель управления Pulse и название источника. Вход в Яндекс и его подписка для этих записей не нужны.
- На Windows виджет использует установленный Microsoft Edge WebView2 Runtime, поскольку Chromium из Qt в этой сборке не содержит AAC. Собственный вспомогательный процесс запускается без консольного окна и без активации отдельного окна. Ошибка стандартного ввода Windows исправлена; ошибки обрабатываются внутри приложения, без системных диалогов.
- Механизм сопоставления учитывает ft./feat. и перечисленные имена исполнителей. Проверяются длительность и версия записи, чтобы не подставить вместо оригинала slowed, инструментал или чужую песню.
- Реально проверены без Яндекса: YUNG TRAPPA/Baksh «Одна ночь», CODE80 «SummerLove», FORTUNA812 «PALADIN». Проверены пауза, перемотка, продолжение и конец записи, а также автоматический поиск SoundCloud-копии по метаданным Яндекса.
- Spotify проверен как потенциальный источник: официальный Web Playback SDK требует личный Spotify Premium. Бесплатный полный стриминг Spotify в эту версию не добавлен; превью не выдаются за полные записи.

- Нажатие песни в каталоге запускает её только в нижнем плеере. Полная карточка и текст открываются нажатием обложки снизу.
- Поиск открытой копии идёт параллельно с ограничением ожидания. Учитываются кредиты исполнителей в названии загрузки SoundCloud; неподходящие ремиксы и несовпадающая длительность не подставляются.
- Волна по записи Яндекса без аккаунта сначала ищет соответствующую запись в открытых источниках и использует их рекомендации. Подключение Яндекса для этого не обязательно. Если подходящих открытых записей нет или источник недоступен, выводится явное сообщение без бесконечного ожидания. Доступность всех песен не гарантируется.
- Профиль: фото, имя, био, статистика, источники и часто прослушиваемые песни. Параметры воспроизведения перенесены в оформление. Частота учитывается по фактическим прослушиваниям, а не по кликам.
- Кнопка «Импортировать треки» под подключением Яндекса переносит все доступные лайки в любимые Pulse пакетами по 100. Повторный импорт не создаёт дубликаты и не удаляет локальное избранное. Переносятся записи библиотеки, не автономные аудиофайлы.
- В обязательном обучении восемь шагов: поиск, любимое, управление, локальные файлы, фон, поддержка, профиль и преимущества подключения Яндекса.
- Увеличен второстепенный текст, улучшен контраст; для мелких подписей используется системный Segoe UI со сглаживанием.
- Вход и поддержка теперь вместе в @PulseMusicHelpBot с логотипом Pulse. Новая сборка обращается только к нему. Обращения поступают владельцу нового бота в личный чат, ответы — через ответ на сообщение.

- Компактный профиль в двух колонках. Громкость и автоматический переход доступны в настройках оформления.
- Три последние основы волн рядом с главной волной; нажатие запускает новую очередь по выбранному треку.
- Полные записи Audius и Яндекса используют локальный кеш; SoundCloud работает через свой официальный онлайн-плеер. Добавлено восстановление зависшего старта. Сообщения воспроизведения видны над управлением на любой странице.
- Поддержка PulseMusic: категория → шаблон описания → до 10 фото/видео/файлов → явная отправка. Владелец получает обращение в личный чат бота и отвечает пользователю ответом на сообщение.

- Обязательный локальный профиль или подтверждённый вход Google/Telegram. Форму нельзя закрыть крестиком и обойти через разделы. Приложение целиком по-прежнему можно закрыть.
- После регистрации запускается обязательное обучение из восьми интерактивных шагов: поиск, любимое, управление, оформление, свои файлы, поддержка, профиль, Яндекс. Шаг завершается только после нажатия подсвеченной кнопки. При закрытии приложения до конца обучение возобновляется при следующем запуске.
- Дымчатые прозрачные панели с регулируемой плотностью 25–85%; окно со скруглением 10 px, при разворачивании — без маски.
- Общий поиск SoundCloud, Audius, Яндекса и локальной библиотеки. Метаданные Яндекса ищутся без подключения аккаунта; карточки точных совпадений исполнителя показываются первыми.
- Выделенная шапка исполнителя и автоматическая загрузка доступного каталога без кнопки «ещё 50». Источники определяют доступность записей. Версии с Explicit и без него специально не отфильтровываются.
- Повторная волна учитывает предыдущую очередь: для открытых источников меняет порядок и предпочитает ещё не предложенные треки; в Яндекс передаётся список предыдущих рекомендаций.
- Убрана длинная подпись на главном экране.

## Вход и данные

Локальная регистрация хранится на компьютере. Почта не проверяется. Пароль сохраняется как PBKDF2-SHA256 с индивидуальной солью и 200000 итераций; исходный пароль не сохраняется и не отправляется. Это локальный профиль, не защита файлов Windows и не облачная синхронизация.

Google: приложение опубликовано для внешних аккаунтов. Настоящий вход в системном браузере через зарегистрированное настольное приложение Pulse Windows, PKCE, случайные state/nonce и loopback только на 127.0.0.1. Проверяются подпись RS256, аудитория, издатель, срок, nonce и подтверждённая почта. Токены Google не сохраняются. В профиле остаются имя, почта и идентификатор. Настольный client_secret в identity-config.json является публичной настройкой установленного приложения, не серверным секретом. Такой клиент нельзя использовать вместо доверенного серверного пароля.

Telegram: бот @PulseMusicHelpBot и отдельный бесплатный Cloudflare Worker. Приложение показывает код запроса, пользователь сверяет его и подтверждает в боте. Сервер получает только имя и ID Telegram, временно хранит одноразовый запрос; после успешной выдачи он удаляется. Запрос действует 5 минут, очистка оставшихся записей запускается каждые 5 минут. Токен бота хранится как секрет Worker, в EXE не включается. Музыка, пароль Pulse, любимое и история на сервер не отправляются. В поддержку передаются явно отправленные описание и вложения: черновики хранятся до 24 часов, обращения — до 30 дней. Вход и поддержка: @PulseMusicHelpBot, Worker pulse-help с отдельной D1-базой. Прежний сервер остаётся только для ранее выпущенных версий.

В identity-config.json находятся только настройки настольного Google-клиента и публичный адрес Telegram-сервера. Серверный исходник отдельно в Pulse-auth-server; секреты туда не включены.

## Доступ к музыке

Пользователь не вводит API-ключи для поиска и открытых записей SoundCloud/Audius. Поиск Яндекса работает без личного входа. При попытке включить закрытую запись приложение ищет совпадающую полную открытую версию по исполнителю, названию и длительности. Похожая или случайная песня не подставляется.

Анонимный Яндекс может отдавать только preview. Такие отрывки не выдаются за полные песни и не скачиваются как полные треки. Если полной открытой записи нет, приложение сообщает, что нужен личный музыкальный аккаунт. Локальный профиль и Google/Telegram-вход не заменяют подписку музыкального сервиса. Подключение собственного Яндекса доступно в профиле. Ни чужой общий аккаунт, ни обход доступа в сборку не включены.

Гарантировать все песни и ремиксы всех платформ невозможно: поддержаны конкретные источники, а сеть, регион, права записи и ответы сервисов меняются. Для текста используется доступная синхронизация строк или слов; отсутствующие тайминги не выдумываются.

## Производительность

Кнопки больше не анимируют металлический блик постоянно в покое. Кеш изображений ограничен приблизительно 24 МБ, большой размер декодированной обложки — 640 пикселей. Вихрь рисуется в уменьшенном разрешении. Предпросмотр фона запускается вручную и не создаёт второй активный эффект по умолчанию.

В оформлении доступны режимы «Экономичный», «Сбалансированный» и «Плавный». Они ограничивают частоту анимации и разрешение; исходные компоненты React Bits не изменены, ограничение кадров применяется вокруг них. Анимацию можно отключить целиком.

В коротком замере нативного вихря на этом компьютере: режим «Плавный» — около 61 кадра/с и 12% одного ядра CPU, «Сбалансированный» — около 31 кадра/с и 4%, «Экономичный» — около 31 кадра/с отображения с более редким обновлением сцены, 3.5%. Это не измерение GPU и не гарантия нагрузки на другом компьютере. Тяжёлые WebGL-фоны используют отдельные процессы браузерного движка.

Для этой Windows-сборки выбран системный Media Foundation: в тестах FFmpeg возникало зависание при сочетании паузы, перемотки и окончания файла; системный движок прошёл эти проверки. Поддержка некоторых форматов зависит от Windows и установленных кодеков. Для диагностики разработчик может переопределить QT_MEDIA_BACKEND=ffmpeg до запуска.

## Сохранившиеся возможности

Главная с волной, история и любимые треки; карточки артистов и каталог; подсказки; ПКМ → волна по треку / слушать следующим / артист / избранное. Яндекс наполняет очередь примерно до 50 рекомендаций и продолжает подгружать её. У открытой волны ассортимент определяется источником; старые треки могут повторяться после прохождения недавней очереди. Обложки последних основ волн запускают их заново. Статистика времени и прослушиваний, аватар, таймер сна и повтор находятся в профиле и оформлении.

## Данные и передача друзьям

Достаточно передать Pulse-0.15.exe. У каждого человека собственная папка %LOCALAPPDATA%\PulseMusic-0.7.1. В ней хранятся profile.json, preferences.json, favorites.json, library.json, appearance.json, backgrounds.json, wave-seeds.json, wave-history.json, onboarding-v08.json, listening.json, avatar.png, audio-cache и lyrics-cache. session.bin — личная сессия Яндекса, защищённая Windows DPAPI. Не передавайте друзьям эту папку с личными данными.

Для собственной песни рядом можно разместить файл с тем же именем и расширением .lrc, .lyricsfile.yaml или .txt. Приоритет у локального текста. Полученные тексты кешируются на 14 дней; запросы LRCLIB ограничены и учитывают Retry-After.

## SoundCloud и системный движок

Для SoundCloud нужен интернет и доступ к публичному мобильному сайту и встроенному плееру сервиса. Правила доступности, регион, удаление и платные ограничения определяет SoundCloud. В приложение не встроены чужие личные токены; закрытые записи и фрагменты не выдаются за полные треки. Сессия виджета и его технический кеш хранятся локально в sc-browser. У SoundCloud собственная обработка запросов и cookie, как при обычном использовании встроенного плеера.

На Windows 10/11 требуется Microsoft Edge WebView2 Runtime. Он установлен на проверенном компьютере и обычно присутствует вместе с Windows/Edge. Runtime не скачивается автоматически и не включён в EXE. Microsoft WebView2 SDK находится в soundcloud-host с LICENSE.txt, обёртка Program.cs собирается системным C# компилятором .NET Framework. Звук локальных файлов/Audius/Яндекса продолжает использовать Windows Media Foundation.

Официальная документация: https://developers.soundcloud.com/docs/api/html5-widget и https://developer.spotify.com/documentation/web-playback-sdk/tutorials/getting-started.


## Открытые исходники и самостоятельная сборка

Оригинальный код Pulse открыт по MIT; сторонние библиотеки и фоны сохраняют собственные лицензии. Исходники приложения и сервера входа/поддержки находятся в Pulse-source.zip в выпуске. Основные Python-файлы также доступны для просмотра в репозитории. Архив содержит ресурсы backgrounds/, fonts/ и soundcloud-host/, необходимые для полной сборки.

Windows x64, Python 3.12:

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python -m PyInstaller --noconfirm Pulse.spec
```

Для запуска из исходников: `.\.venv\Scripts\python main.py`. Если скачаны только файлы репозитория, сначала распакуй Pulse-source.zip и работай в папке Pulse-source. В архиве также лежит Pulse-auth-server с серверным кодом. Работа сервера требует собственных переменных окружения; они не опубликованы. В публичном identity-config.json настройки Google оставлены пустыми: разработчик указывает собственное desktop OAuth-приложение. Готовый официальный EXE уже настроен для входа.

Сборка содержит исходники .NET-помощника WebView2 в soundcloud-host/Program.cs; его можно пересобрать штатным C#-компилятором Windows. Приватный ключ подписи выпусков хранится отдельно и не входит в исходники. Для собственного канала обновлений сгенерируй собственную пару ключей и замени PUBLIC_KEY/REPOSITORY в updates.py.

Контрольная сумма EXE опубликована в SHA256SUMS.txt. Она позволяет проверить совпадение скачанного файла с опубликованным, но не является доказательством отсутствия ошибок или вредоносного кода. Сборки PyInstaller не гарантируют побайтовую воспроизводимость между компьютерами; исходники позволяют проверить поведение и собрать собственную копию.
