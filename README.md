## В этих версиях

- Альбомы исполнителей с названиями, обложками и открытием песен. Яндекс и Audius подгружают страницы автоматически. Полнота и доступность каталога определяются источником.
- «Для вас» учитывает любимых исполнителей, жанры и историю прослушивания.
- Импорт открытых лайков SoundCloud по имени профиля или ссылке, без повторов. Ограниченный список не выдаётся за полный.
- Единая новая иконка P в Windows, Android и @PulseMusicHelpBot.
- Таймер сна удалён на обеих платформах.
- Android: сразу открывается Telegram, обучение подсвечивает настоящие элементы интерфейса, в мини-плеере есть обложка, поиск показывает карточки артистов. Из профиля убраны настройки волны и экспорт диагностики.
- Встроенные обновления загружаются и проверяются автоматически. После обнаружения подлинного обновления пропустить его нельзя; можно закрыть приложение. При недоступной сети запуск не блокируется. Windows автоматически заменяет EXE и перезапускается; Android требует разрешения и системного подтверждения установки APK. Предыдущие Android-альфы нужно один раз обновить вручную.

## Проверки

Android: 28 автоматических тестов, сборка приложения и тестового APK, Lint без ошибок, подпись прежним сертификатом. Windows: проверки рекомендаций, полного прохода страниц альбомов, простого импорта, обязательного окна обновления, запуск исходников и готового EXE с независимой папкой данных. Сетевые ответы каталогов Яндекса, Audius и SoundCloud проверены отдельно.

Реальное сетевое прослушивание и длительная фоновая работа Android на Samsung/Poco остаются этапом проверки на физическом телефоне. APK подписан отладочным ключом для тестирования. Подписанные каналы и контрольные суммы защищают обновления от подмены, но не доказывают отсутствие ошибок.

## Открытые исходники

- [Полный Windows-проект и сервер](Pulse-source.zip); отдельный архив `Pulse-source-0.16.zip` в выпуске Windows. Основные Python-файлы доступны непосредственно в репозитории.
- [Android-проект](Pulse-Android-source-0.1.0-alpha3.zip) и [инструкция Android](ANDROID.md).
- Приватные ключи подписи, токены бота, сессии сервисов и личные профили в исходники не включаются. Публичный Windows `identity-config.json` содержит пустую конфигурацию Google: для собственной сборки зарегистрируй свой настольный OAuth-клиент. Готовый официальный EXE настроен для входа.

Windows: Python 3.12 x64. Распакуй полный архив и в папке Pulse-source выполни:

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python -m PyInstaller --noconfirm Pulse.spec
```

Android: JDK 17, SDK 35, Gradle Wrapper включён. Укажи свой sdk.dir в local.properties и выполни `gradlew.bat assembleDebug testDebugUnitTest lintDebug`.

## Данные и доступ

Локальные профили хранятся на устройстве; пароли — PBKDF2-хеши. Google и Telegram подтверждают личность у сервиса. Библиотека, профиль и история не синхронизируются между ПК и телефоном. При обновлении приложения данные сохраняются.

SoundCloud/Audius доступны в рамках открытого каталога. Яндекс подключается личным аккаунтом; подписку и доступ к записям определяет музыкальный сервис. Общий чужой аккаунт и обход ограничений доступа не используются. На Windows SoundCloud требует Microsoft Edge WebView2 Runtime.
